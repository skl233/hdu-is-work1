### 1. POST /auth/login with a wrong password (must be 401)
$ curl -i -X POST http://127.0.0.1:5055/auth/login -d '{"username": "alice", "password": "wrong"}'
HTTP/1.1 401
{
  "error": "invalid username or password"
}

### 6. SQL injection attempt in the login form (must be 401, no token)
$ curl -i -X POST http://127.0.0.1:5055/auth/login -d '{"username": "' OR '1'='1' --", "password": "' OR '1'='1' --"}'
HTTP/1.1 401
{
  "error": "invalid username or password"
}
------------------------------------------------------------------------------
### 7. POST /api/posts with an XSS payload (output must be escaped)
$ curl -i -X POST http://127.0.0.1:5055/api/posts -d '{"title": "<img src=x onerror=alert(1)>", "content": "<script>alert('xss')</script>"}'

  }
}
